# YouTube Clone

Proyecto educativo desarrollado con UIKit para practicar desarrollo iOS.

## Requisitos

- Xcode
- iOS 15.0+
- YouTube Data API v3

## Configuración

Antes de ejecutar el proyecto, agrega tu propia API key de YouTube Data API en:

`YouTube_Clone/Utils/Constants.swift`

```swift
static let apiKey = "YOUR_API_KEY"
